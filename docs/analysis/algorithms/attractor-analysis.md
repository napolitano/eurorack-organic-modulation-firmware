# Attractor algorithm engineering analysis

## 1. Purpose and scope

Attractor is a deterministic Organic-bank mode built around the Hénon map. Its purpose is structured non-periodic or periodically-windowed motion generated by a nonlinear dynamical system rather than a random-number process.

## 2. Mathematical foundations

Michel Hénon's original two-dimensional mapping is

$$
x_{n+1}=1-a x_n^2+y_n,
$$

$$
y_{n+1}=b x_n.
$$

Hénon's 1976 paper studies the classic $a=1.4$, $b=0.3$ case: M. Hénon, *A two-dimensional mapping with a strange attractor*, Communications in Mathematical Physics 50, 69–77, DOI: <https://doi.org/10.1007/BF01608556>.

Drift fixes

$$
b=0.30
$$

and maps Texture over

$$
1.20\le a\le1.40.
$$

The parameter sweep is a **structure** control, not a mathematically monotonic chaos control. Periodic windows may occur as $a$ changes.

## 3. Reference algorithm

State uses signed Q2.14 coordinates. Each Speed cycle:

1. advances the current 32-bit interpolation phase;
2. when the phase wraps, promotes the previous destination to segment start;
3. evaluates one Hénon iteration with the current Texture-derived $a$ parameter;
4. linearly interpolates the visible $x$ coordinate between consecutive map points;
5. maps the Q2.14 coordinate $[-2,2)$ to DAC code 0..4095.

The map itself is therefore discrete, but the emitted CV is continuous between map points.

## 4. Relationship to upstream Drift

There is no upstream Attractor mode. The implementation reuses the Classic exponential Speed mapping and its phase-overshoot-preserving accumulator helper. No pseudo-random generator is involved.

## 5. Behavioral analysis

At $a=1.4$, $b=0.3$, the fixed-point orbit from the selected origin follows the well-known Hénon-map form while remaining comfortably inside Q2.14 coordinate rails. Sweeping $a$ changes the orbit topology and may enter periodic windows or chaotic regions.

Interpolating between successive map points is a musical design layer on top of the discrete map. It prevents abrupt 12-bit sample-and-hold jumps and lets Speed control the travel time between nonlinear destinations.

## 6. Findings and classification

- **Reference model:** Hénon's published two-dimensional map.
- **Sound-design choice:** $a$ is swept from 1.20 to 1.40 while $b$ remains 0.30.
- **Sound-design choice:** only the interpolated $x$ coordinate is emitted.
- **Implementation trade-off:** interpolation is Q0.12 so coordinate-difference products stay in signed 32-bit arithmetic.
- **Documentation requirement:** Texture must not be advertised as a monotonic amount of chaos.

## 7. Improvement strategy

Any wider $a$ range must first be exhaustively checked for boundedness in the fixed-point implementation. A future two-coordinate output would require hardware changes because the original Drift exposes only one DAC output channel in the current design.

## 8. Computational cost on ATmega328P

Per sample the mode performs one Speed mapping, one phase addition and one 16-by-12-bit interpolation multiply. The nonlinear Hénon iteration requires additional fixed-point multiplications only when a Speed cycle rolls over, not on every sample.

Persistent state is one phase accumulator, two Hénon points and one initialisation flag.

## 9. Optimization opportunities

The chosen Q2.14/Q0.12 representation intentionally avoids 64-bit arithmetic. The nonlinear iteration should remain outside the per-sample hot path. No floating-point implementation is justified on ATmega328P.

## 10. Verification and test strategy

Required evidence:

- Texture maps monotonically to exact $a$ endpoints;
- iteration from known points matches the reference equation within fixed-point rounding tolerance;
- all 1024 Texture values remain bounded for long fixed-point orbits from the chosen origin;
- interpolation is monotonic between ordered endpoints and remains bounded;
- coordinate-to-DAC mapping has exact rail/centre behavior;
- complete algorithm runs are deterministic and remain in 0..4095;
- timing and resource guardrails pass in the Organic firmware image.

## 11. Engineering assessment

Attractor has a stronger external mathematical reference than the other project-defined Organic modes. The fixed-point implementation is small and bounded over the selected parameter range; the key discipline is to describe its parameter behavior accurately rather than reducing a nonlinear bifurcation structure to a single "chaos" knob.
